Build a new offline-first Android mobile app called DocPocket.

DocPocket is a private document vault + form assistant. It should help me store important files, personal info, official documents, form details, and document kits in one secure offline place.

This app is NOT a normal file manager.
This app is NOT a notes app.
This app is NOT a cloud drive.

Main idea:
When I need to fill a visa form, school form, travel form, send my passport image, share a PDF, copy my phone number, copy my address, or collect required documents, I should open DocPocket and find/share/copy everything in seconds.

The app must be:
- offline only
- local only
- private
- secure
- fast
- minimal
- Android-first
- APK-build ready
- export/import capable
- not laggy
- not overloaded

Do NOT add:
- cloud sync
- account/login server
- ads
- social features
- backend
- analytics
- AI features
- unnecessary heavy features

==================================================
SECURITY REQUIREMENTS
==================================================

This app may store passport images and sensitive PDFs, so security is mandatory.

Required:
- PIN lock
- optional biometric unlock
- auto-lock after app goes background
- auto-lock after inactivity
- hide sensitive content on recent-apps preview if possible
- local-only storage
- no network calls
- no analytics
- no cloud backup
- no third-party upload
- warning before storing sensitive documents

PIN:
- user can set PIN on first launch or enable later
- store PIN securely, not plaintext
- use secure storage for PIN hash/auth data
- allow changing PIN
- allow disabling PIN only after entering current PIN

Biometric:
- biometric unlock is optional
- PIN remains fallback

Privacy Mode:
- toggle to blur sensitive values and file previews
- hide passport numbers partially by default, like A123****7
- allow temporary reveal

Clipboard safety:
When copying sensitive info, offer:
- clear clipboard after 60 seconds
- show small notice: “Copied. Clipboard will clear soon.”

Important:
Do not commit or bundle any real documents in the GitHub repo.

DOCUMENT TOOLS
==================================================

Add useful document tools, but keep them lightweight.

1. Filename generator

One-tap rename suggestions:
- Passport_Mekan_Jumakulyyev.pdf
- FlightTicket_MWIT_2026.pdf
- VisaPhoto_Mekan.jpg
- ConsentForm_Mekan.pdf
- Transcript_Mekan.pdf

User should be able to:
- generate name from document type + custom name/date
- apply suggested name to file metadata
- optionally rename exported/shared filename if possible

2. File size reducer

Useful because visa/school websites often reject large files.

MVP:
- compress image
- resize image
- convert image to PDF if practical
- show original size and new size

Examples:
Compress image:
Original: 5.2 MB
Compressed: 1.1 MB

If PDF compression is too heavy, add it to Version 2.

3. Image to PDF

Allow user to convert:
passport image / ID photo / document photo
into a PDF.

4. Send-ready versions

A document can have variants:
- original
- compressed
- cropped
- black-and-white
- PDF version

Example:
Passport
- Passport original.jpg
- Passport compressed.jpg
- Passport PDF.pdf

Do not overcomplicate MVP.
At least support original + compressed version for images.

5. Document requirements notes

For each file or kit, user can store:
- required file type
- max file size
- photo size
- filename rule
- submission note

Example:

BACKUP / IMPORT
==================================================

Backup is very important.

Settings should include:
- Export backup
- Import backup
- Last backup date
- Storage used
- Number of files
- Number of info cards
- Number of kits

Because the app contains sensitive files, backup needs clear warnings.

MVP backup:
At minimum export metadata:
- info cards
- kit definitions
- checklist states
- file metadata
- file names/categories/tags
- settings

Better backup:
Export full backup including files.

Preferred full backup format:
docpocket_backup_YYYY-MM-DD.zip

Inside:
- manifest.json
- files/

manifest.json:
{
  "version": 1,
  "exportedAt": "...",
  "files": [],
  "infoCards": [],
  "kits": [],
  "settings": {}
}

If ZIP is too complicated for MVP:
- export metadata JSON first
- add full ZIP backup in Version 2
- allow sharing files individually

Security:
- warn user if backup includes sensitive documents
- password-encrypted backup is preferred for Version 2
- if backup is unencrypted, clearly label it as unencrypted

Import:
- choose backup file
- validate version
- preview counts:
  files found
  info cards found
  kits found
- ask confirmation before replacing current data
- never partially import corrupted backup
- if import fails, current data remains unchanged

Import modes:
- Replace current data for MVP
- Merge later
